# playing-cards · 中国扑克玩法平台原型

线上扑克小游戏原型集合，目标是聚合多种中国扑克玩法（斗地主、打升级、捉黑枪、炸金花、5·10·K、掼蛋），内置纯娱乐虚拟积分，支持好友房 + AI 陪玩。

> 当前为 **原型阶段**：规则引擎 + 可玩 HTML，浏览器直接打开即玩，无需后端。

## 直接试玩

用浏览器打开对应 `.html` 文件即可（无需安装、无需联网）。

- 打升级：亮主阶段持有级牌可亮主/无主；出牌必须跟花色，20 秒内未出自动出最小牌；AI 回合时可打开底部「牌桌聊天」打字或点默认话逗对手。
- 副数与区域玩法在顶部设置栏选择，点「开始游戏」按新配置重开。

## 合规说明

虚拟积分仅游戏内计分与排行，**不可提现、不可兑换、不碰现金**，规避棋牌涉赌红线。
